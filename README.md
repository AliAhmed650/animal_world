# عالم الحيوانات

تطبيق Flutter فيه ٩٧ حيوانًا بصور حقيقية وأصوات حقيقية، مع لعبة «أي حيوان يصدر هذا الصوت؟».

- **الصور:** تُجلب وقت التشغيل من ويكيبيديا (واجهة `page/summary`).
- **الأصوات:** تُجلب وقت التشغيل من ويكيميديا كومنز (بحث `filetype:audio`)، وإن لم يوجد شيء يُستخدم تسجيل مضمّن في مقالة ويكيبيديا.
- التطبيق يعرض مصدر كل صورة وصوت والترخيص (رخص مفتوحة تتطلب نسب العمل لأصحابه).
- يحتاج إنترنت. الحيوانات الصامتة (زرافة، سمك، فراشة…) بدون زر صوت.

## أسهل طريقة للحصول على APK (بدون تثبيت Flutter)

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد كله (بما فيه `.github`).
2. في `lib/services/wiki_service.dart` غيّر `kHeaders` وضع رابط مستودعك وبريدك (تطلب ويكيميديا ذلك).
3. أنشئ Release بوسم مثل `v1.0.0` (أو `git tag v1.0.0 && git push --tags`).
4. يعمل Workflow «Build APK & Release» تلقائيًا ويرفع `animal-world.apk` إلى صفحة الـ Release.
   يمكنك أيضًا تشغيله يدويًا من تبويب Actions وتنزيل الملف من Artifacts.

## التشغيل على جهازك

```bash
flutter create . --platforms=android --project-name animal_world --org com.animalworld
# أضف داخل android/app/src/main/AndroidManifest.xml قبل <application>:
#   <uses-permission android:name="android.permission.INTERNET"/>
flutter pub get
flutter run
```

## إضافة حيوان

أضف سطرًا في `lib/data/animals.dart`:

```
id|الاسم بالعربي|English|عنوان مقالة ويكيبيديا|التصنيف|كلمات بحث عن الصوت|اسم الصوت
```

اترك كلمات البحث فارغة لحيوان لا يصدر صوتًا.

## ملاحظات

- أصوات كومنز بصيغة OGG غالبًا: تعمل على أندرويد، وقد لا تعمل على iOS.
- نتائج البحث عن الأصوات تتفاوت في الدقة. إن وجدت صوتًا غير مناسب لحيوان، غيّر كلمات بحثه في `animals.dart`.
